# Orientation cube

Behaviour comes from FreeCAD's NaviCube (unchanged); the look and the extra commands are ours. Rendered variants: `docs/icons/contact-sheet.html` → "Orientation cube variants" (generated by `tools/cubevariants.py`).

## Function (brief §3.4) and where it lives

| Function | Provided by |
|---|---|
| 6 labelled faces, 12 edges, 8 corners → 26 animated views | NaviCube; the same 26 views are also commands (`Kovac_View_*`, findable in search) |
| Hover highlight, drag to orbit, roll 90°, step to adjacent faces | NaviCube |
| Home: go / set current as home / reset | `Kovac_Home`, `Kovac_SetHome`, `Kovac_ResetHome` (view bar, radial menu, search) |
| Define current view as Front (relabels the cube) | `Kovac_DefineFront` / `Kovac_ResetFront`: snaps the camera to the nearest axis frame, stores it in the document and rewrites the cube's six labels live; all view commands follow it |
| Perspective / orthographic | view bar |
| Fit to view on view change | preference `FitOnViewChange` |
| Hide cube | FreeCAD preference `ShowNaviCube` |
| Size, HiDPI, theme, semi-transparent idle → opaque on hover | NaviCube parameters set by our preference pack (`CubeSize` 120, `InactiveOpacity` 55 %) |

## Design variants

All variants are a cube with chamfered edges and truncated corners: 6 square faces, 12 edge strips, 8 corner triangles, every region clickable.

| | A · Forged (**default until you choose**) | B · Facet | C · Wire |
|---|---|---|---|
| Chamfer | 0.16 of half-size: crisp, small edge targets | 0.34: big, easy edge/corner targets | 0.07: nearly a plain cube |
| Faces | `surface2` neutral, edges a touch darker | mid-grey `model` tone, solid | white, thin outline |
| Edges | neutral border 1.0 px | border 1.4 px | strips outlined in their axis colour (X red, Y green, Z blue) |
| Labels | UI font, semibold, muted text colour | bold, white on grey | medium weight, normal text colour |
| Hover | **axis-tinted**: a face tints with its axis colour, edges/corners with the accent | accent fill | axis-tinted like A |
| Controls | roll arrows top-left/right; step chevrons on all four sides; home (origin target) bottom-left; menu (three dots) bottom-right; all muted, accent on hover | same placement | same placement |
| Idle | 55 % opacity | 55 % | 55 % |

## What ships today vs. what needs a core patch
Variant A is applied through NaviCube parameters (colours, chamfer, border, font, weight, size, opacity, labels). Three parts of the design need C++ changes (`docs/core-patches.md` #1–3) and are not live yet:

- axis-tinted hover (today a single accent hover colour)
- our own control glyphs
- Home / "define as Front" entries on the cube's own menu (today they are in the view bar, radial menu and search)

**Status: awaiting the owner's choice of A, B or C.**
